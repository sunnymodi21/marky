How it works

Copy. It converts. Paste.

No window to open, no button to press. Marky sits in your menu bar and recognizes Markdown the instant it lands on your clipboard.

1

Copy anything

Grab Markdown from Claude Code, Codex, another terminal agent, a README, or your notes with a normal ⌘C. Marky converts only real Markdown — commands, URLs, and source code pass through untouched.

2

Marky rewrites the clipboard

The clipboard gets rich text and styled HTML representations — while the plain-text copy keeps your original Markdown, character for character. Nothing is ever destroyed.

3

Paste anywhere

Rich editors like Google Docs, Slack, Notion, and Mail get formatted text. Terminals and code editors still get your raw Markdown. Every app receives the version it wants.

FAQ

Questions, answered

Does it work with Claude Code and Codex?

Yes. Copy their Markdown output from the terminal as usual. Marky detects and formats it for rich-text apps while keeping the original Markdown available for terminals, editors, and developer tools.

Does my clipboard ever leave my Mac?

No. Detection, conversion, history, and OCR all run on-device. Marky makes no network requests, and your history is a local file you can delete at any time.

Will it mangle things that aren't Markdown?

Marky scores each copy before touching it. Bare URLs, shell commands, source code, and very long texts are deliberately left alone. And even when it does convert, the plain-text version of the clipboard keeps your original characters — so a "wrong" conversion never loses data.

What about passwords and sensitive copies?

Anything marked concealed or transient by password managers (the nspasteboard.org convention used by 1Password and friends) is skipped entirely — never converted, never recorded in history.

Why does Marky ask for the Accessibility permission?

Only the history window's paste-on-pick uses it, to press ⌘V into the app you came from. Decline it and everything else still works — picking a clip simply copies it for you to paste yourself.

What does it run on?

macOS 15 Sequoia or later. It's a tiny menu-bar app — no dock icon, no login nags, a few megabytes of memory.
